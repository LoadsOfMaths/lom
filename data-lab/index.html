Settings

Choose a topic, then rename its categories, change the colour, add an optional symbol or emoji, or add and remove categories (2 to 8). Changes are saved on this device.

These are the contexts offered on the Discrete Data and Simple Frequency Table tabs. Use {n} in the description where the number of values should appear. Values are whole numbers from the smallest to the largest value you set (at least 3 apart). The Simple Frequency Table uses at most 10 values, starting from the smallest.

These are the contexts offered on the Grouped Frequency Table tab. Use {n} in the description where the number of values should appear. Values are whole numbers from the smallest to the largest value, sorted into groups of the width you set (3 to 10 groups).

These are the contexts offered on the Continuous Data tab. Use {n} in the description where the number of measurements should appear. Measurements are random values between the smallest and largest, rounded to the decimal places you choose.

These are the contexts offered on the Bivariate Data tab. Use {n} in the description where the number of points should appear. Each context has two variables, x (across) and y (up), with the smallest and largest values that can occur.
