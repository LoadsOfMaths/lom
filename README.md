# LoadsOfMaths games

Each game lives in its own folder as `index.html`, so every game has its own link. `index.html` in the top folder is the menu page.

## Updating a game

Replace the game's `index.html`, commit with a message naming the game (for example "Potato: added new sequence types") and push. The published link updates within a couple of minutes.

## Adding a game

Create a new folder with the game's `index.html`, then add an entry to the menu page.
